# 雀镜 QueLens

面向微信小程序的麻将牌型学习工具。首版方向：成都血战到底。当前为底层框架开发版，尚不可提交上架。

## 开发

1. 使用 Node.js 22 或更高版本；无第三方运行时依赖。
2. `npm run check` 检查配置、页面文件与脚本语法；`npm test` 运行核心与页面逻辑测试。
3. 微信开发者工具导入本仓库根目录，读取 `project.config.json`。当前 `touristappid` 仅用于本地尝试，游客模式能力以工具实际支持为准。
4. 注册小程序后替换为真实 AppID，设基础库 3.1.0 或以上并进行真机预览。AppSecret 只放服务端，不提交到仓库。

## 当前能力

原生 JS / WXML / WXSS / JSON 页面；手动录入14张未碰杠手牌、定缺校验、普通胡牌/对对胡/七对/清一色及根数判断。规则引擎额外支持碰、杠的结构输入，页面尚未开放副露编辑。根不等于杠结算。

番数策略独立、带版本标识；未确认配置不返回数值。拍照入口关闭，仅有可测试的隐私授权及选择照片适配层，无真实 AI、上传、后端、登录、持久化或整局结算。

## 结构

- `miniprogram/domain/`：牌编码、结构判断、规则配置与基础番计算，无微信 API 依赖。
- `miniprogram/services/`：平台能力适配。
- `miniprogram/pages/`：手动录牌及说明。
- `tests/`：核心算法、隐私流程、页面操作测试。
- `docs/`：架构、场规确认、微信上架准备。

具体范围及限制见 [架构](docs/architecture.md)、[规则决策](docs/rules.md)、[微信兼容与上架](docs/wechat-release.md)。CI 已配置，但远端是否运行成功应以 Actions 实际结果为准。
